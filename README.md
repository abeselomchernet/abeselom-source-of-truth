# Abeselom Source of Truth

An evidence-backed public portfolio for Abeselom Girum Chernet.

## Live sites

- Production: <https://abeselomchernet.github.io/abeselom-source-of-truth/>
- QA preview: <https://qa.abeselom-mvp-preview.pages.dev/>

## What is included

- Executive bio, career, education, and training
- Research, projects, volunteering, and technical portfolio
- Certification records with verification links and source-listed credential IDs
- Evidence statuses and boundaries
- Interactive graph, explainable matcher, scenario views, and recruiter-facing lenses

The site is static and public-only. Private documents, identity documents, credentials, passwords, and backend services are not included.

## Validation

The GitHub Pages workflow validates the public projection and JavaScript syntax before deployment. Release QA covers desktop/mobile layout, keyboard navigation, internal navigation, graph search/filtering, matcher presets/results, scenario tabs, and audience views.

## Repository boundary

This repository is the public Source of Truth MVP. The separate Verified Evidence Platform is developed in its own repository and must not be merged into this static public site.

## Local preview

Serve this directory with any static HTTPS-capable preview server. Do not expose the parent workspace or private source documents.
